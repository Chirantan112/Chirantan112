<br />

<h3 id="-catalyst--deterministic-ai-hybrid">Why it matters</h3>

<p>
A material-harmonization system built around a deliberate engineering boundary:
<strong>AI can advise, but deterministic technical logic owns the final decision.</strong>
</p>

<table>
  <tr>
    <td width="33%" valign="top"><strong>INPUT</strong><br />Messy / legacy material descriptions</td>
    <td width="33%" valign="top"><strong>REASONING</strong><br />Normalize → extract attributes → match → validate</td>
    <td width="33%" valign="top"><strong>DECISION</strong><br />Authoritative mapping or human-review escalation</td>
  </tr>
</table>

<br />

<strong>Engineering highlights</strong>

<ul>
  <li>Deterministic normalization and technical attribute extraction</li>
  <li>Record linkage against a controlled canonical catalog</li>
  <li>Optional Local NLP and Gemini advisory layers</li>
  <li>Independent technical validation before accepting AI-supported evidence</li>
  <li>Conservative <code>UNCERTAIN</code> path instead of forcing weak matches</li>
  <li>Reproducible synthetic benchmark and automated verification</li>
</ul>
